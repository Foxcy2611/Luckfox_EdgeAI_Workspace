# Tools

Thư mục này chứa bộ công cụ chuyển đổi mô hình ONNX sang RKNN trên Ubuntu để triển khai lên LuckFox RV1106.

- `rknn-toolkit2-v1.6.0/` — Bộ RKNN-Toolkit2 của Rockchip, dùng để chuyển đổi và lượng tử hóa mô hình sang RKNN INT8.
- `.venv-rknn/` — Môi trường Python 3.11 riêng để cài và chạy RKNN-Toolkit2 cùng các thư viện phụ thuộc.

Cả hai thư mục được thiết lập cục bộ và được Git bỏ qua. Xem [hướng dẫn cài đặt RKNN-Toolkit2](../Docs/Down_RKNN_Toolkit2.md).
